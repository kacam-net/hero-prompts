# 性格倾向：不给你贴标签，先问你要事例

网上那些四个字母的测试，问的是**「你更倾向于哪一种」**——
而所有人回答这种问题时，答的都是**自己希望成为的那个人**。
「我更喜欢提前做好计划」，谁不想这么说。

这一批换了个问法：**只问最近一次你具体做了什么。**

> 不问「你是不是容易被打乱」，问**「上周三被打乱的那一下，你第一个动作是什么」**。
> 不问「你重感情还是重道理」，问**「你那次改口，是被他说的哪一句说服的」**。

**追问是这一批唯一的价值。** 计分是算术，不需要大模型；
**把「我比较内向」逼成「那天散场我回家躺了两小时没说话」，才需要。**

## 和别处的测试不一样在哪

| | 常见的测试 | 这一批 |
| --- | --- | --- |
| 问什么 | 你更倾向于哪一种 | **最近一次你具体做了什么** |
| 答案来源 | 你对自己的判断 | **你说得出的事例** |
| 说不清怎么办 | 照样算进分数 | **记成「说不准」，不进判定** |
| 一套题 | 测完给一个四字母 | **一份测一个场景，跨场景自己对账** |
| 结果 | 一个类型 + 一段性格描述 | **一张带原话证据的卡片 + 自评和事例哪儿对不上** |

最后那一行是这批东西真正想给的：
**不是告诉你你是谁，是告诉你你说的和你做的差在哪。**

## 十份不是同一张卷的十个版本

一开始的方案是「出十套平行题，做腻了换一套」。**那个方案过不了
[drill-authoring.md](../drill-authoring.md) 第零步的粒度判据**：
十套同构的题，底牌就是同一份记分规则，一个字不改就能互换——那是模板不是题。
而且更实际的问题是，**同一个人做第一套是 A、做第三套变成 B，他会觉得这东西坏了。**

所以切法换成了**十个场景**：每一份在一个具体场景里问四个维度，
其中**一维是主战场**（这个场景能问透的那一维），另外三维只顺带过一遍，
**问不出来就明确写「这个场景测不出」，不许硬凑。**

于是「换一份再做」变成了这批东西最有意思的部分：

> **跨场景结果不一致，不是 bug，是这一批唯一拿得出手的结论。**
> 「你在会议室里按道理走，在家里按关系走」——这句话，任何一套问卷都给不了你。

## 怎么用

1. 挑一份，**新开一个空对话**。
2. 把那个文件里 `---` 分隔线**之后**的全部内容复制过去。分隔线之前是给你看的说明。
3. **先用一两句话说出你要讲的是哪一次**（哪天的事、跟谁、什么事），然后等它问。
4. 中途三个口令：

   | 口令 | 作用 |
   | --- | --- |
   | `跳过` | 这一问不想答，记一笔就过 |
   | `换一个` | 换一次经历重来 |
   | `复盘` | 立刻跳到收尾，输出卡片 |

   **没有 `提示`，也没有 `直说吧`。** 这里没有标准答案——
   模型一「提示」，就等于告诉你哪种回答算哪一侧，**后面每一句都被污染了**。
5. 结束时它输出一张卡片，**存下来**（上面有一行 `场景：__ ｜ 日期：__`）。
   攒够三四张之后，拿去做 [`90-cross-check.md`](90-cross-check.md) 那一份对账。

几条使用上的坑：

- **别在同一个对话里连做两份。** 上一份的上下文会让它对你有先入判断——
  这一批尤其致命，它会开始往一个类型上凑。
- **它一开始提字母就打断它。** 这批最重要的一条铁律是「字母只准出现在最后那张卡片上」。
  它要是中途说了一句「这说明你偏内向」，**这一份就作废了，重开一个对话。**
- **别挑一次特别极端的经历。** 那天你发着烧、或者对面是你最讨厌的人——
  测的是那一天，不是你。挑一次普通的。
- **不想讲就说「跳过」。** 这批问的是你的真实生活，
  没有任何一问是必须答的，跳过会如实记成「这一维证据不足」。

## 建议的路线

- **就想快点知道四个字母** → `01` → `03` → `06` → `08`，
  四份各测一维，再用 `90` 合成一次。**四份分开做，别在一个对话里。**
- **已经知道自己是什么类型，想验一下** → 先做主战场是你**最确信那一维**的那份。
  最有意思的结果往往出在这儿——自评和事例对不上的，通常正是你最确信的那一维。
- **只想试一份** → `06`。它最短、最不涉及隐私，
  而且是四维里**自评最不准**的一维，对照最明显。

## 边界（这一批写死的几条）

1. **不预测、不建议、不评价这个人。** 不说哪一侧更好、不说你适合做什么工作、
   不说你该找什么样的伴侣、不说你该怎么改。
2. **不问成因。** 只问发生了什么、你做了什么，
   **不追童年、不做心理分析**——那是另一回事，不在这里做。
3. **不是诊断。** 这几份判的是「你在这个场景里的行为倾向」，
   和任何医学或心理学上的判断没有关系。
4. **四个字母不是科学分类，重测会变。** 页面上和卡片上都要这么写。
   这批东西的可信度上限就是「你那天说的事例有多准」，不会更高。
5. **不用 MBTI 这个招牌。** 那是注册商标，题目和描述全部自己写。

这四条在三个地方各写了一遍（这份 README、每份的铁律、每张卡片的末尾），
是有意重复的——[drill-series-expansion.md](../drill-series-expansion.md) 第十二节
那条「边界要写三遍」。

## 为什么这么写（几个决定）

- **字母是全程封口的，只准出现在最后那张卡片上。**
  这是这批最硬的一条。模型一句「这说明你偏内向」，
  后面每一个回答都会往那边靠——比剧透一道算法题的答案严重得多，
  因为这里的「答案」是你自己，你会不自觉地去圆它。
- **自评一律记账，但不参与判定。** 每份都要求模型：
  用户自己说的「我比较内向」记成**自评**，判定只看事例，
  最后把两栏并排。**这一栏是整批东西最值钱的输出。**
- **允许「这个场景测不出」，而且鼓励这么写。**
  一个场景问不出四维是常态。硬凑四维是这批最容易犯的错，
  所以每份的底牌末尾都单独写了一节「另外三维为什么大多测不出」。
- **`08` 要求换一个领域再答一遍。** S/N 受学的东西本身影响太大
  （学游泳谁都先动手），一次样本不够。两次不一致就降强度、写「不稳定」——
  **比硬给一个结论诚实。**
- **姿态是拷问，但收着两处。** 不评价这个人、不追「为什么你是这样」。
  这批和 [`your-own/`](../your-own/) 同为 B 型（材料是你的、清单是我们的），
  但那批可以追到你哑口无言，这批不行——问的是你的生活，不是你的方案。
- **没有 `提示` / `直说吧`，和 `your-own/` 同理**，但原因更重：
  那批是「没有你那件事的标准答案」，这批是「一提示就污染样本」。

## 这一批和 `drill-series-expansion.md` 第六节的关系

那份规格里写着「明确不收：人生决策和情绪心理」，理由是**没有底牌、
必然滑向替人做决定**。这一批擦着那条线，所以说清楚它凭什么不在那一类里：

- **有底牌。** 每一份的底牌是「这个场景里四维的行为标记 + 这个场景特有的误判」，
  而且那份清单挪到隔壁那份上完全不成立（社交场景的误判是
  「社交技能冒充 E」，决策场景的是「职场措辞包装 F」）——过第零步的判据。
- **不替人做决定。** 边界第 1 条写死了：不预测、不建议、不评价。
  它输出的是一张带原话证据的对照表，不是一个人生建议。
- **不做心理分析。** 边界第 2 条：不问成因。
  「为什么你会变成这样的人」那一问，是滑向陪聊的唯一入口，直接封掉。

**如果这三条有一条守不住，这个系列就该按那份规格撤掉。**
