# 算法 · 语音版：报数、报栈、报分支

[上一层](../README.md) 那十份的共同纪律是**手推优先于写代码**。
**语音版把这条纪律变成了硬约束**——因为你连代码都写不了，只能推。

## 「手推」在语音里叫什么

打字版说「在长度 2 的数组上把 l 和 r 推一遍」，
语音版把它固定成了一个格式，**每一份都有自己的那句**：

| 哪一份 | 报什么 | 格式 |
| --- | --- | --- |
| [01](01-binary-search.md) | **报数** | 「第几轮，左是多少，右是多少，中是多少」 |
| [02](02-two-pointers.md) | **报窗口** | 「这一步左端在哪、右端在哪、窗口里是哪几个数、和是多少」 |
| [04](04-monotonic-stack.md) | **报栈** | 「栈里从底到顶是哪几个下标，这一步弹了谁，结算出什么」 |
| [06](06-union-find.md) | **报父节点** | 「一号的父亲是几，二号的父亲是几，谁是根」 |
| [07](07-prefix-sum.md) | **报前缀** | 「第零个是多少，第一个是多少……减的是第几个」 |
| [10](10-backtracking.md) | **报分支** | 「第一层有几个分支，前两个往下长出的东西一样吗」 |

**这些格式不是形式主义**：含糊的「然后就缩小了」「然后就弹出来了」
在打字时看着像回事，**说出口就立刻听得出是空的**。
每一份的收尾都多了一栏，专门报你**有几步是报不出来、含糊过去的**——
那几步就是你其实没推过的地方。

## 另外三处改动

**一、变量和记号全说中文。**
左、右、中，不念单个字母；
「两头都含」「左含右不含」，不念方括号；
「n 乘 log n」「n 的平方」「二的 n 次方」，不念那个大写字母。

**二、不许查。** [03](03-complexity.md) 和 [05](05-heap-topk.md) 尤其严——
这两份本来就是心算考试，
你一说「我查一下」，它就回**「先按你现在记得的说一个数量级」**。
（说「我算一下」可以。）

**三、几份的核心机制在语音下自己变硬了**，这是意外收获：

- [08](08-dp-state.md)（状态定义）：它只考一件事——
  **你能不能用一句话把状态说清楚。**
  打字时含糊的定义能靠方程糊过去；说出来的时候，
  教练会当场回你一句「你这句话我能读出两种意思」。
  收尾会报你**被回了几次**——那个数就是你的真实分数。
- [09](09-greedy.md)（贪心）：**「我试了几个例子都对」这句话，
  说出口的时候你自己都听得见它有多虚。**
- [02](02-two-pointers.md) 第三幕：**「给我一个理由，不要举例子」**——
  举例子在嘴上比在纸上更容易滑过去，所以这一份会盯到你说出那句论证为止。

## 怎么用（豆包）

1. 挑一份，**新开一个空对话**，把 `---` 之后的全部内容粘贴进去
   （或者存成一个智能体的人设）。
2. **切到语音通话**，说一句「开始吧」。
3. **它会一直逼你报数。** 答「然后就那样了」会被打断——这是有意的。
4. 口令直接说出来：「跳过」「换个说法」「**再念一遍**」「直说吧」「复盘」。
5. **末尾的底牌别自己先读。**

## 建议的路线

不用按编号刷，和打字版一样按你眼下的病挑：

- **想不出解法** → [08](08-dp-state.md)。「看得懂题解、自己想不出来」一多半卡在状态定义，
  **而这一份在语音下最能暴露你到底想清楚了没有。**
- **写得出但老错边界** → [01](01-binary-search.md) → [07](07-prefix-sum.md)。
  这两份治的是同一种病：背公式而不是用定义推，
  **而「减的是第几个」这句话说不出来，就是背的。**
- **认不出题型** → [04](04-monotonic-stack.md) → [02](02-two-pointers.md)。
- **面试要问复杂度** → [03](03-complexity.md)。纯心算，不许查。
- **贪心老是错** → [09](09-greedy.md)。
