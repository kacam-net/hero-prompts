# 计算机系统 · 语音版：一场心算考试

[上一层](../README.md) 那十份的共同底色是**逼你说出数量级**。
把它们搬到语音上，这条底色反而更纯粹了 ——
**因为语音堵死了那个后门：你没法一边查一边答。**

## 语音版多做了四件事

**一、不许查。** 每一份的铁律里都加了这条：
你一说「我查一下」，它就回一句 **「先按你现在记得的说一个数量级。」**
说「我算一下」可以，说「我搜一下」不行。

打字的时候你查了什么、想了多久，没人知道；
电话里**从问题问完到你开口那几秒，就是你真实的熟练度**。

**二、所有图和表改成一项一项报。**

| 原来是 | 语音版怎么给 |
| --- | --- |
| [01](01-address-translation.md) 那张地址翻译流程图 | 一条路口述：先查哪儿、命中怎样、没命中谁去走 |
| [07](07-random-read.md) 那张延迟阶梯 | **一级一级报，每级停半拍** |
| [10](10-tcp-stall.md) 那张「六种形状」 | 一种一种说，说完一种停一下 |
| [06](06-context-switch.md) 的「两笔账」 | 一笔一笔说，每笔配一个数量级 |

**三、代码由它念，你复述。**
[04](04-memory-barrier.md) 那段两个线程的代码，教练**一行一行念给你听，
念完让你复述一遍**。
**这一步本身就是第一道题**：复述得出来，说明你真的在脑子里跑了这段代码，
而不是扫一眼觉得「看懂了」。两个线程也改叫**甲和乙**——A 和 B 在电话里听着太像。

**四、每份的收尾多一栏语音专属的账。**
[01](01-address-translation.md) 报「我有几次想查、被按住了」；
[05](05-false-sharing.md) 报「八个长整数正好一行，这个算式是我自己算的还是被喂到嘴边的」；
[07](07-random-read.md) 报「哪些数是我自己算出来的」；
[08](08-fsync.md) 报「我有没有亲口说出那句『到这一步为止，断电就是丢』」。

## 怎么用（豆包）

1. 挑一份，**新开一个空对话**，把 `---` 之后的全部内容粘贴进去
   （或者存成一个智能体的人设）。
2. **切到语音通话**，说一句「开始吧」。
3. **它会一直逼你算数。** 答「有开销」「比较快」会被打断——这是有意的。
4. 口令直接说出来：「跳过」「换个说法」「**再说一遍**」「直说吧」「复盘」。
5. **末尾的底牌别自己先读。**

## 建议的路线

- **想补数量级感** → [07](07-random-read.md) → [09](09-connection-setup.md)。
  这两份在语音下最像真的口试，**而且是纯心算**。
- **线上排查用得上** → [02](02-malloc.md) → [10](10-tcp-stall.md) → [06](06-context-switch.md)。
  [10](10-tcp-stall.md) 的主战场是「我说一个现象，你猜是哪一种」——
  **天然的口头抢答。**
- **写多线程代码** → [04](04-memory-barrier.md) → [05](05-false-sharing.md)。
  [04](04-memory-barrier.md) 治正确性，[05](05-false-sharing.md) 治性能，两份互不替代。
- **做存储和数据库** → [08](08-fsync.md) → [07](07-random-read.md) → [03](03-mmap-vs-read.md)。

几份之间是串着的，**串着做比单独做划算**：
[01](01-address-translation.md) 的缺页在 [02](02-malloc.md) 里是主角；
[03](03-mmap-vs-read.md) 的内核文件缓存在 [08](08-fsync.md) 里决定断电丢不丢；
[05](05-false-sharing.md) 的缓存行和 [06](06-context-switch.md) 的缓存冷是同一层硬件；
[09](09-connection-setup.md) 的队头阻塞在 [10](10-tcp-stall.md) 里再出现一次。
