# 计算机系统：一次只钻一块

和 [algorithms/](../algorithms/) 是同一套路子 —— **学习型、引导姿态、
底牌是「常见的想错」** —— 只是换了一个领域。

## 每一份只钻一块，而且是「哪一部分中的哪一块」

这批题的粒度是两级收窄的：**不是「内存管理」，是「TLB miss 和缺页差在哪」；
不是「网络」，是「第一个字节到达之前来回跑了几趟」。**

判据是那条通用的：**把这一份的底牌拿到隔壁那一份上去，还成立吗？**
不成立才写。一份叫「操作系统内存管理」的题，底牌只能写成
「理解虚拟内存、页表、缺页」—— 那种东西你自己对模型说一句
「你来考我内存管理」也能得到，我们就白做了。

## 这一批的共同底色：**说得出数量级**

十份里每一份都在逼同一件事 —— **把「快」「慢」「有开销」换成一个数**。
它们串起来就是一张延迟表：

```
L1 缓存        ~1 ns          TLB miss       ~100 周期
内存           ~100 ns        缺页(minor)     ~1~2 μs
上下文切换      ~1~3 μs（直接）  缺页(major)     ~100 μs
NVMe 随机读     ~50 μs         fsync          ~0.5~5 ms
同城 RTT       ~1~5 ms        跨太平洋 RTT    ~150~250 ms
```

**这张表是容量估算的地基**：说不出这些数，就没法判断一个方案是必要的
还是过度设计（和系统设计那批的第二幕是同一件事）。

## 怎么用

1. 挑一份，**新开一个空对话**。
2. 把那个文件里 `---` 分隔线**之后**的全部内容复制过去。
3. 什么都别说，等它问第一个问题。
4. **它会一直逼你算数。** 答「有开销」「比较快」会被打断 ——
   这是有意的，这一批练的就是这个。
5. 中途四个口令：

   | 口令 | 作用 |
   | --- | --- |
   | `跳过` | 立刻进下一幕 |
   | `换个说法` | 这一处换个角度再讲一遍 |
   | `直说吧` | 讲完整答案，然后要我复述 |
   | `复盘` | 立刻跳到收尾，输出复盘卡片 |

6. **末尾的底牌别自己先读** —— 那一栏「常见的想错」写的就是每一问的答案。

## 想用语音练？走 [oral/](oral/)

这一批的底色是「逼你说出数量级」，**搬到语音上这条底色更纯粹** ——
因为语音堵死了那个后门：**你没法一边查一边答**。
[oral/](oral/) 下面十份都加了这条铁律：你一说「我查一下」，
它就回「**先按你现在记得的说一个数量级**」。
另外所有图表改成一项一项报（延迟阶梯一级一级、六种形状一种一种），
`04` 那段两线程的代码改成**它念、你复述**。

## 建议的路线

- **想补数量级感** → `07` → `09`。这两份最直接地在建那张延迟表，
  做完再回头看别的会顺很多。
- **线上排查用得上** → `02`（内存涨了看哪个数）→ `10`（卡住的六种形状）
  → `06`（线程池该开多大）。
- **写多线程代码** → `04` → `05`。`04` 治的是正确性，`05` 治的是性能，
  两份互不替代。
- **做存储/数据库相关** → `08` → `07` → `03`。
  `08` 是「数据库为什么要有 WAL」的地基。

几份之间是串着的：`01` 的缺页在 `02` 里是主角；`03` 的 page cache 在 `08` 里
决定断电丢不丢；`05` 的缓存行和 `06` 的缓存冷是同一层硬件；
`09` 的队头阻塞在 `10` 里再出现一次。**串着做比单独做划算。**

## 为什么这么写（几个决定）

- **姿态和算法那批一样是引导，不是拷问。** 这一批的东西「不知道就是不知道」，
  追到底只会让人关窗口。所以卡住时它先问你卡在哪一层，
  给脚手架不给答案，讲完要你复述。
- **每一份都逼数量级。** 这是这一批和算法那批最大的不同：
  那边逼手推，这边逼算数。理由一样 —— **说得出结论说不出数字，就是背的。**
- **不做「八股清单」。** 十份都是「一次具体的操作在硬件上发生了什么」，
  不是「进程和线程的区别」那种。后者只会得到一段名词解释。
- **每份都有一条反剧透：在我说出可行做法之前不许提到任何专有名词。**
  学习类最大的风险是模型太急着展示知识 —— 一上来就说「这是 TLB miss」，
  你就再也没机会自己推出来了。
