# 故障排查 · 语音版：像真的给值班的人打了个电话

[上一层](../README.md) 那六份是**你问它答**。这一批还是你问它答，
只不过现在是**一通电话**——而电话会暴露一件打字藏得住的事：
**你到底会不会问问题。**

## 语音版改了什么

**一、一次只答一个问题。** 你一口气抛三个，它会说
「你刚才问了三个，我先答第一个」，然后**只答那一个**。
听起来是刁难，其实是这一批最值钱的新规矩：
**打字时你可以一次问五个、然后从一堆回答里挑有用的；
电话里不行，你必须先想清楚「我现在最该知道的是哪一个数」。**
收尾时它会报你这么干了几次。

**二、要图就念给你听。** 火焰图、对象直方图、抽样记录——
它会用嘴一项一项念：「最宽的一块是什么，占多少」「排第一的是什么，大概多少个」，
念两三项就停下来问你还要不要往下。

这反而是读这些东西的正确姿势：**你要的本来就只是那两个数。**
[06](06-report-mismatch.md) 那份最明显——十条差异记录的时间点被一个一个念出来，
**念到第四五个你就听出来「怎么全在凌晨」**，比看表格还快。

**三、多了一个口令：「捋一遍」。** 语音没法往回翻聊天记录，
所以你可以随时说「捋一遍」，它就把你到目前为止问到的结论按顺序复述一遍，
**不许加新东西，也不计入记账**。

**四、所有专有名词说中文。** 说「连接重置」不说 RST，
说「防火墙那台设备」不说一串英文缩写，说「一个哈希表的节点对象」不念英文类名。

## 那条不能破的规矩（照旧，而且更重要）

**它不许主动提示下一步该看哪里。** 你不问，它就不说——哪怕你在原地绕十分钟。

现实里没有人会在你身边说「你应该看看火焰图」。
**排查能力就是「想得到该问什么」这一件事**，
一旦模型开始给方向，你练的就变成了阅读理解。

想不动的时候有口令「给个方向」，但它**会计入记账**。

## 怎么用（豆包）

1. 挑一份，**新开一个空对话**，把 `---` 之后的全部内容粘贴进去
   （或者存成一个智能体的人设）。
2. **切到语音通话。** 它会先把现场分三口气说给你听，然后停下——**接下来该你开口了。**
3. 口令直接说出来：「给个方向」「公布真相」「换一个」「再说一遍」
   「**捋一遍**」（语音版独有）「复盘」。
4. **手边留张纸。** 这是唯一建议你动笔的一批——
   不是为了记提示词，是因为你没法往回翻，线索得自己攒着。
5. **末尾的真相别自己先读**——读了这一份就没得练了。

## 建议的路线

- **第一次用语音做，从 [01](01-p99-spike.md) 开始**，它的诊断链最干净，四问到底。
- **然后做 [02](02-partial-errors.md)**，「只有一部分 → 找共同点」是复用率最高的一条。
- **[06](06-report-mismatch.md) 是语音收益最大的一份**，而且不需要任何系统知识。
- **[05](05-flaky-timeout.md) 留到最后。** 它在语音下明显更难——
  线索散在四五个回答里，你得自己串起来。**「捋一遍」这个口令就是为它加的。**
