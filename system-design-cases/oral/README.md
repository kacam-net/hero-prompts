# 系统设计 · 语音版：没有白板的那种面试

[上一层](../README.md) 那 17 份是打字用的。这里是同样 17 道题的**语音版**——
而系统设计恰恰是**最像真实面试**的一批：
真正的系统设计面试就是**一边说一边被追问**，
只不过现场还有块白板，**这里连白板都没有**。

## 语音版改了什么

**一、你画不了图，只能用嘴把结构搭出来。**
每一份的铁律里都有这条：你一说「我画一下」，它就回
**「我看不见，说给我听——一站一站说，谁调谁，同步还是异步」**。

**框图最擅长藏的就是「这两个东西到底谁调谁」**——
画两个框连一根线，听的人自己会脑补方向；说出来就藏不住了。

**二、不许报菜名。** 这是这一批新加的账：
你一开始念一串中间件的名字，它就打断
**「先说这一个在这里是干什么的，为什么非它不可」**，
并且**记下你干了几次，收尾时报给你**。

**三、容量估算变成真的心算。** 不许查、不许「我算算大概」——
**「现在算，说出每一步。」**
[04](04-short-url.md) 的进制位数、[05](05-feed.md) 的平均粉丝数、
[11](11-file-upload.md) 的那笔带宽乘法、[12](12-geo-dispatch.md) 的位置上报量，
**全都是当场报数。**

**四、收尾多两张语音专属的账**：
**我是几秒之内开始讲方案的**（第一幕还没问清楚就开讲，是最稳定的失分项），
以及**我有几次在报菜名**。

| [91](91-your-own-project.md) 讲自己的项目 | 「高并发」打出来很自然，**说出口、对面立刻回你一句「多少？」，那两秒沉默骗不了人**。它还会数你说了多少次「一般来说」 |
| [10](10-rate-limiter.md) 限流器 | 「限流熔断降级」含混着连成一串说，**打字看不出来，说出口立刻露馅** |

| [90](90-cross-cutting-drill.md) 快问快答 | 它本来就是快问快答，**打字会把节奏拖垮，说话才是它的原生形态** |

## 怎么用（豆包）

1. 挑一道题，**新开一个空对话**，把 `---` 之后的全部内容粘贴进去
   （或者存成一个智能体的人设）。
2. **切到语音通话**，说一句「开始吧」。**然后等它问，别抢答。**
3. 口令直接说出来：「跳过」「提示」「直说吧」「再说一遍」
   「**捋一遍**」「复盘」。
   **「捋一遍」是语音版新加的**：它把你到目前为止说过的方案按顺序复述一遍，
   不加新东西——**因为你没法往回翻聊天记录。**
4. **手边留张纸。** 不是为了记提示词，是因为你得自己攒着那些数字。
5. **末尾的底牌别自己先读。**

## 建议的路线

和打字版一样，**不要按编号刷**：

1. **先做 [90](90-cross-cutting-drill.md)**，它是零件测试，而且**是这批里最适合语音的一份**。
2. **再做 [04](04-short-url.md)**，最简单，用来熟悉语音下的节奏和口令。
3. **然后按方向挑**：
   交易金融走 [01](01-flash-sale.md) → [02](02-payment.md) → [03](03-order-inventory.md)；
   社交内容走 [05](05-feed.md) → [06](06-im.md) → [07](07-leaderboard-counter.md)；
   基础架构走 [10](10-rate-limiter.md) → [13](13-job-scheduler.md) → [12](12-geo-dispatch.md)。
4. **最后做 [91](91-your-own-project.md)，而且要反复做。**
   **在语音下，它是这整个仓库里最不留情面的一份。**
