# 英语 · 语音版：这一批的打字版才是妥协

别的系列是「打字版是原版，语音版是改造」。**英语这批反过来**：
拼读、字母、开口说，**本来就该用耳朵和嘴做**，
[上一层](../README.md) 那五份是在打字这个限制下能做到的最好版本。

这里的五份把那个限制去掉了。

## 语音版多出来的四件事

**一、音标不再是符号，是声音。**
打字版里写 `/æ/`，你得先学会读音标；语音版里教练**直接把那个音发给你听**，
再配一个锚点词：「你听，就是 cat 里的那个音」。
**规矩写死了：一个斜杠、一个方括号都不许念。**

**二、它真的听得见你读错。**
这是整批最大的差别。打字版问「A 读什么」，你回答的是**你以为自己读的那个音**；
语音版里你得真的读出来，**V 读成 W 当场就被抓**。
[01](01-alphabet.md) 那份甚至反过来考你：它随机念一个字母，你说是哪个。

**三、抓「说漏」——打字版根本不存在的一类错。**

| 哪一份 | 抓什么 | 为什么打字版抓不到 |
| --- | --- | --- |
| [03](03-present-perfect.md) | 时态选对了，**助动词和动词变形被吞掉** | 写的时候你会加词尾，说的时候一律掉 |
| [04](04-articles.md) | 规则全懂，**冠词整个说漏** | 写 `a question` 不会漏，说出来十次漏六次 |
| [02](02-phonics.md) | 假词测试**从听完到开口用了几秒** | 打字看不出你是脱口而出还是想了三秒 |

这三条合起来是一句话：**「知道」和「嘴上有」是两件事，
而打字会把这两件事混在一起。** 补的方法也完全不同——
一个是再看一遍规则，一个是慢速朗读。

**四、[05](05-speak-up.md) 多了第五个维度「听得清」。**
原来四维是结构、准确、词汇、流利；语音版加上**发音和重音**，
而且**流利不再靠猜**：超过三秒的停顿会被数出来。
外加一张只有语音能开的账单：填充词、要求重复的次数、切回中文的次数。

## 怎么用（豆包）

1. 挑一份，**新开一个空对话**，把 `---` 之后的全部内容粘贴进去
   （或者存成一个智能体的人设）。
2. **切到语音通话**，说一句「开始吧」——
   [05](05-speak-up.md) 那份说 "Let's start."，**它全程只说英语**。
3. 口令直接说出来：「跳过」「换个说法」「**再读一遍**」「直说吧」「复盘」。
   **「再读一遍」是语音版新加的**：你没听清，它就把那个词或者那个音原样再发一次。
4. **找个能出声的地方，而且别戴着降噪耳机小声嘟囔。**
   这一批有一半的产出来自「它听见了你实际发出来的声音」。
5. **末尾的底牌别自己先读。**
   **唯一的例外是 [05](05-speak-up.md)**：它没有底牌，只有一张评分表，**那张表该先看。**

## 建议的路线

- **完全从头开始** → [01](01-alphabet.md) → [02](02-phonics.md)。
  地基没打对的人，学到拼读会莫名其妙地卡住。
- **能读能写但说不出口** → 直接 [05](05-speak-up.md)，
  先拿一张卡看看自己在哪一维最弱，再回头补对应的。
- **写出来没问题、说出来总被听岔** → [03](03-present-perfect.md) 和 [04](04-articles.md)。
  **这两份的语音版和打字版考的其实不是同一件事**——
  打字考你知不知道，语音考你嘴上有没有。
- **[05](05-speak-up.md) 值得反复做**，每次换一个话题。它不是「学会了就过了」，是拿来量的。
