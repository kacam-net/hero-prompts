# 英语：一次只钻一块，而且是「学好这一块要掌握什么」

和 [algorithms/](../algorithms/)、[computer-systems/](../computer-systems/)
是同一个姿态 —— **学习型、引导、不许夸** —— 但切法上有一处特别要说清楚。

## 不按教材目录切

按目录切是这样的：字母 / 自然拼读 / 时态 / 冠词 / 写作……
**那是内容的分类，不是掌握度的分解。** 按它切出来的题，底牌只能写成
「这一节讲什么」，等于把教材复述一遍 —— 而那种东西你自己对模型说一句
「给我讲讲时态」也能得到。

正确的切法是：**先划出一小块，再问「学好这一块实际上要掌握哪几件事」，
那份清单才是底牌。**

「26 个字母」这一块就是最好的例子。它的内容**不是「背下 26 个字母」**，
而是下面这五件：

1. **字母名 ≠ 字母音**（A 叫 /eɪ/，但在 cat 里读 /æ/）—— 后面自然拼读的全部地基
2. 元音字母 5 个、辅音 21 个、y 两栖 —— 这个分类比字母顺序重要得多
3. 形近易混（b/d、p/q、m/n）各自的辨认锚点
4. 音近易混（B/P/V、G/J、V/W）—— 其中 V 是中文母语者的标志性难点
5. 大小写不是装饰，是句子边界和专名的信号

**这五件事就是那一份的底牌**，Drill 的活儿是逐条问、你卡住就引导。
判据也跟着换了：不是「答对几条」，是**「你能不能用自己的话把这五条讲一遍」**。

## 专治母语干扰

这批题选的都是**说中文的人特别容易卡住的地方**，而不是「英语里比较难的语法点」：

- 中文没有时态标记 → 我们习惯用「昨天」「已经」代替动词变形
- 中文没有冠词、不强制标记单复数 → 冠词只能靠语感撞运气
- 拼音是一一对应的表音系统 → 用它的直觉去期待英语拼写，一定会失望
- 普通话没有 /v/ → V 和 W 分不开

所以每一份的底牌里都有一栏专门写**母语干扰**，那是这批题真正的价值所在。

## 怎么用

1. 挑一份，**新开一个空对话**。
2. 把那个文件里 `---` 分隔线**之后**的全部内容复制过去。
3. 什么都别说，等它问第一个问题。
4. 中途四个口令：`跳过` ｜ `换个说法` ｜ `直说吧` ｜ `复盘`。
5. **末尾的底牌别自己先读** —— 那一栏「常见的想错」写的就是每一问的答案。
   **唯一的例外是 `05-speak-up`**：它没有底牌，只有一张评分表，
   而那张表**应该先看**（见下）。

## 想用语音练？走 [oral/](oral/) —— 这一批尤其该去

别的系列是「打字版是原版」。**英语这批反过来**：拼读、字母、开口说，
本来就该用耳朵和嘴做，上面这五份是打字这个限制下能做到的最好版本。

[oral/](oral/) 去掉了那个限制：**音标不念符号，直接把音发给你听**；
**它真的听得见你把 V 读成 W**；还能抓一类打字版根本不存在的错 ——
**时态选对了但动词变形被吞掉、冠词规则全懂但一开口就漏**。
`05` 那份还多了第五个维度「听得清」，流利度不再靠猜，超过三秒的停顿会被数出来。

## `05` 为什么没有底牌

**这是这个板块里唯一一份「评分表公开」的题。**

别的题的底牌写的就是每一问的答案，提前读了就没得练。
而 `05` 考的是**当场的表现** —— 知道自己按结构 / 准确 / 词汇 / 流利
四个维度被打分，既泄露不了什么，**也恰恰是你该先知道的事**：
不知道被看什么，就不知道该练什么。

它的收尾卡片也因此不同：不是覆盖表，是**四维各一个分 + 你自己的原话当证据**，
**没有原话的分数不算数**。

## 建议的路线

- **完全从头开始** → `01` → `02`。地基没打对的人，学到拼读会莫名其妙地卡住。
- **能读能写但说不出口** → 直接 `05`，先拿一张卡看看自己在哪一维最弱，
  再回头补对应的。
- **写出来的句子总被说「不地道」** → `03` 和 `04`。
  这两块合起来占了中文母语者语法错误的一大半，而且都是每句话都可能出现的东西。
- **`05` 值得反复做**，每次换一个话题 —— 它和别的题不一样，
  不是「学会了就过了」，是拿来量的。

## 为什么这么写（几个决定）

- **过程语言 = 目标语言。** `05` 全程英语，包括反馈和评分卡；
  卡住可以用中文求助，但**会被记一笔** —— 换出去几次本身就是一个指标。
- **不许替我造句。** 这是 `05` 最重要的一条：给提示（定义、类别、首音、
  更简单的说法）可以，**给句子不行** —— 代笔出来的句子你下次还是说不出。
- **不逐句纠错。** 只挑「挡住理解的」和「重复出现的」。
  每个冠词都纠一遍会让人不敢开口，而这一份要的恰恰是让人一直说下去。
- **母语干扰单独成栏。** 「英语里比较难的语法」和「说中文的人容易错的地方」
  是两个清单，这批题选的是后者。
- **`locale` 是素材的语言，不是练习的语言。** 这五份提示词都是中文写的指令
  （其中 `05` 的指令内容是「全程说英语」），所以它们是 `zh-CN` 素材。
