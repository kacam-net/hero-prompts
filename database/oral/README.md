# 数据库 · 语音版：戴着耳机被追问

[上一层](../README.md) 那八份是**打字**用的：里面有下划线、有 SQL 代码块、有表格、
有 ✅🟡❌。这些东西念出来全是噪音 ——「user 下划线 id」「反引号 Extra 反引号」
「括号五逗号十括号」，语音一读就废。

这里是同样八块知识点的**口语版**，专门给豆包（或者任何支持语音通话的大模型）用。
**知识点一个没少，底牌一个没改**，改的只是它怎么说、怎么问、怎么判。

## 改了哪五件事

**一、所有标识符说中文。** `user_id` → 「用户编号」，`idx_us` → 「用户加状态那个索引」，
`t(id, c, d)` → 「编号、丙、丁」。全文找不到一个下划线。

**二、SQL 全部口述。** 不再有代码块，改成
「查用户编号等于七、并且状态等于二的订单，按下单时间从新到旧取前二十条」。
[07-explain.md](07-explain.md) 那份的执行计划，改成教练**一项一项念给你听**，
念完一项停下来问你一句。

**三、「画时间线」改成「报拍子」。** 语音里画不了两列表格，所以并发那几份
（[04](04-isolation-levels.md)、[05](05-row-locks.md)、[06](06-lost-update.md)）
一律用「第一拍甲做了什么，第二拍乙做了什么，第三拍谁提交了」来说。
两个事务叫**甲和乙**，不叫 A 和 B —— 语音里 A 和 B 听着太像。

**四、加了一组语音铁律。** 每一份开头那一段是新写的，最要紧的四条：

- **每次说话不超过三句、大概三十秒，说完必须停下来等你出声**（模型一开口就停不下来，这条最值钱）
- **不许念清单**。任何有好几条的东西，一条一条说，说完一条等你回应
- **不许念符号**。不说下划线、括号、箭头、星号，也不说「冒号」「反引号」
- **容忍语音转文字的错别字**。按数据库的上下文理解你的意思，别纠正你的用词，
  也别把「嗯」「那个」当成答案

**五、判卷改成口播。** ✅🟡❌ 变成「我自己说出来的 / 你提示之后我才说出来的 / 我完全没提到」，
逐条清单改成**一次念三条、停下来问你要不要继续**，自测题一道一道念。

## 怎么用（豆包）

1. 挑一份，**新开一个空对话**。
2. 把那个文件里 `---` 分隔线**之后**的全部内容粘贴进去 ——
   豆包里更省事的做法是**存成一个智能体的人设**，以后直接打电话给它。
3. **切到语音通话**，第一句说：「我用的是 MySQL 8，开始吧。」
   用 PostgreSQL 的就说 PostgreSQL，它会按那家讲并且点出结论不同的地方。
4. 中途的口令直接**说出来**：
   「跳过」「换个说法」「直说吧」「再说一遍」「等一下」「复盘」。
   比打字版多了两个 —— 「再说一遍」是没听清，「等一下」是让它闭嘴别替你填空。
5. **末尾的底牌别自己先读**，那一栏「常见的想错」写的就是每一问的答案。

## 两个提醒

**一、语音版更累，别排两份。** 同样的内容，说出来比打字慢，而且没法回看上一句。
一次一份，说完就下课。

**二、说不出来才是真的说不出来。** 打字的时候你可以边写边想、可以删了重写；
语音逼你一口气把话说完 —— **这一栏里所有「一律记成背的」的判定，在语音下会触发得多得多。**
那不是它变严了，那是原来那层遮羞布没了。
