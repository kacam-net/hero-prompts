# 讲自己的 · 语音版：沉默也是答案

[上一层](../README.md) 那 13 份是打字用的。这里是同样 13 份的**语音版**。

这一批的判卷线是：**给不出具体的，就是空的。**
**而语音把这条线变得更锋利**——原因有两个：

**一、沉默会被听见。**
「最早哪一天你就知道要延期了」「改这个数据的地方一共有几处」
「说出十个名字」——**这些问题后面那几秒钟，比任何回答都诚实。**
每一份的收尾都会把那几秒报给你。

**二、你没有草稿。**
打字时「配合有点问题」这句话，你会停下来斟酌措辞、删掉重写；
**说出口的就是第一版——而第一版才是你真的那么想的那一版。**

## 语音版最要紧的一条新规矩

**它不许填补你的沉默。**

这一批是**没有底牌的 Drill**（底牌是「这一类事的根因清单」，
不是你那件事的答案），所以最大的风险从来不是「答不出来」，而是：

> 你说「记不清了」，模型接一句「可能是因为当时排期紧吧」，你一点头——
> **那句就变成了你的记忆。**

打字时你还能盯着那句话想想对不对；**语音里它滑过去得太快了。**
所以每一份的铁律第二条都写死了：**我停下来想的时候，你闭嘴等着，
不要「嗯」、不要提示、更不要替我补半句。**

## 怎么用（豆包）

1. 挑一份，**新开一个空对话**，把 `---` 之后的全部内容粘贴进去
   （或者存成一个智能体的人设）。
   **[05](05-resume.md) 和 [23](23-rebuttal.md) 要把简历、审稿意见一起贴进去**，
   再切语音。
2. **切到语音通话**，**先用一两句话说出你要讲的是哪件事**，然后等它问。
3. 口令直接说出来：「跳过」「换一个」「再说一遍」「捋一遍」「复盘」。
   **没有「提示」和「直说吧」**——这批的底牌是「这一类事的根因清单」，
   不是你那件事的答案。**你答不出来就是一条结论，它会如实记下来。**
4. **它开始安慰你的时候，提醒它看铁律里「不要夸我」那条。**
   复盘和故障这两份尤其容易触发安抚人格——
   **那会让整件事变成情绪疏导，而不是复盘。**

## 建议的路线

和打字版一样，**按你眼下要做的事挑**：

- **手上有个方案要提** → 先在答辩那三份里找对得上的，都不是就用
  [03](03-design-defense.md)。
  **在评审会之前自己挨一遍问，比在会上被问住便宜得多**——
  而语音版尤其像那个会。
- **刚延期 / 刚发现没人用 / 刚出过一次事故** → 对应那一份，**趁记得住**。
  故障和延期尤其要趁热做，**时间线过一周就说不准了**。
- **准备找工作** → [05](05-resume.md) → [04](04-behavioral.md)。
- **准备答辩或复试** → [21](21-thesis-defense.md) / [22](22-research-interview.md)。
  **这两份在语音下和真实现场的差别最小**，值得在正式那天之前做两遍。
