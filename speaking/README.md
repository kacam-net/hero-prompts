# 讲清楚：讲解和谈判都是当场表现

这一批是 **C 型**（表现量表）：材料是你自己带的，判的不是对错，
是**你当场说成了什么样**。所以它的收尾不是覆盖表，是**逐维打分 + 引你的原话当证据**。

和别的系列最大的差别有两条：

**一、它扮演的是听你说话的那个人。** 外行、决策者、新同事、HR、你的上级 ——
每一份都规定了这个人**懂什么、不懂什么、在意什么**，然后照着这个人的反应给你压力。

**二、它不许替你组织语言。** 你卡壳、找词、说了半句改口，它都等着。
帮你把话接完，这一场就白做了。

## 谈判那三份的边界

和「做人」那个范畴、和解梦是同一条：

- **不预测结果。** 不会告诉你「这样说大概能谈到多少」。
- **不替你做决定。** 接不接、走不走，它一个字都不说。
- **不评判对方**（你老板、你同事、对面那家公司）。
- **不给法律和合同条款上的意见**，问到就一句「这个得问专业的人」。

它只做一件事：**把你这一场说了什么、漏了什么、在哪一句上自己松了口，
原样摆给你看。**

## 怎么用

1. 挑一份，**新开一个空对话**。
2. 把 `---` 之后的全部内容复制过去。
3. **尽量出声说。** 这批题练的是当场表现，在心里过一遍和说出口是两件事。
4. 四个口令：`跳过` ｜ `换个说法` ｜ **`暂停`**（跳出角色问一句元问题，
   这个系列独有）｜ `复盘`。

## 建议顺序

**「讲到你卡住的地方」是这一批的地基** —— 它不需要任何设定，练的是最基本的那件事：
你以为自己懂的东西，讲到第几层会卡住。

之后按你眼下的事挑：要去申请资源做「讲给要拍板的那个人」；
带新人或者要写文档做「讲给刚来的新同事」；正在面试做「你期望多少」和「offer 来了」；
在现在的公司想谈涨薪做最后那一份。

**每一份都值得反复做，每次换一个题材** —— C 型的题不像知识题会「做完」。
