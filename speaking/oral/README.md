# 讲清楚 · 语音版：这一批本来就该用嘴做

[上一层](../README.md) 那七份写的是「**尽量出声说**」——那是打字场景下的一句请求。
在这里它不是请求，是前提。

**这一批是所有系列里语音收益最大的一批**，因为它考的东西
（结论先行、被打断、卡壳、沉默里撑不撑得住）**在打字时全部会被悄悄修掉**：
你可以把结论剪到最前面再发送，可以把「嗯……那个……」删掉，
可以在对面沉默的三秒里从容地组织第四稿。**说出口就都没了。**

## 语音版多做了四件事

**一、把只有语音能做的压力接上了。**

- **真的打断**（02、04）：听到行话、听到层级跳了，当场出声打断，不等你说完。
- **真的沉默**（05、06、07）：你报完一个数，它停三到五秒不说话。
  **这是薪资谈判里最有效的一招，打字版根本演不出来。**
- **真的计时**（03）：老板只听三十秒。打字版数「第几句话说到诉求」，语音版直接数秒。

**二、加了几张只有语音能开的账单。** 收尾时会报给你：

| 账单 | 出现在 | 它暴露什么 |
| --- | --- | --- |
| **口水词账** | 01、02 | 「那个」「就是说」突然变密的那一段，就是你没想清的那一段 |
| **打断次数** | 02、04 | 前三分钟占了几次——密集说明你上来就没铺垫 |
| **多少秒才说到诉求** | 03 | 技术的人最稳定的失分项 |
| **沉默里撑了几秒** | 05 | 撑不住的人会自己补一句「当然也可以谈」 |
| **改了几次口** | 06 | 那句要被转述给老板的话，一遍成型的人是真想清楚了 |
| **虚词账** | 07 | 「我觉得」「应该算是」密集的地方，你自己也不太信 |

**三、白板没了**（04）。原版你还能画个框画条线糊过去，语音里只能用嘴搭结构——
**框图最擅长藏的就是「这两个东西到底谁调谁」**，说出来藏不住。

**四、评分表改口播。** 五个维度一维一维报，每维报完停一下，每维都要引你的原话当证据。

## 两种底牌，别搞混（和打字版一样）

**讲解那四份（01 到 04）末尾是「评分维度」，该先看。** 知道自己按哪几维被打分，
泄露不了任何答案。

**谈判那三份（05 到 07）末尾是「底牌」，别先看。** 那里面是对面的预算、
能动的杠杆和话术——知道了就没什么可练的了。

## 谈判那三份的边界（照旧）

不预测结果、不替你做决定、不评判对方、不给法律和合同条款上的意见。
它只做一件事：**把你这一场说了什么、漏了什么、在哪一句上自己松了口，原样摆给你看。**

## 怎么用（豆包）

1. 挑一份，**新开一个空对话**，把 `---` 之后的全部内容粘贴进去
   （或者存成一个智能体的人设，以后直接打电话给它）。
2. **切到语音通话**，说一句「开始吧」。
3. 口令直接说出来：「跳过」「换个说法」「**暂停**」（跳出角色问一句元问题，这个系列独有）
   「等一下」「复盘」。
4. **找个能出声的地方。** 这一批小声嘟囔是练不出来的——
   压力有一半来自「话说出去了收不回来」。

## 建议顺序

和打字版一样，**「讲到你卡住的地方」是地基**，它不需要任何设定。

但如果你只打算做一份：**做「你期望多少」**。
那三到五秒的沉默是这整个仓库里最便宜、也最像真事的一次压力测试——
**你会在第一次就发现自己张嘴补了一句什么。**
