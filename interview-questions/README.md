# 面试快问：一次会话只问一道题，往下挖五层

这一批和 [computer-systems/](../computer-systems/)、[database/](../database/)、
[algorithms/](../algorithms/) 那几批练的**不是同一件事**：
那边是**学习型、引导姿态**，题目是「一次具体的操作在硬件上发生了什么」；
**这一批是面试型、拷问姿态，题目就是面试官会开口的那一句原话。**

| | 计算机系统 / 数据库 / 算法 | **面试快问** |
| --- | --- | --- |
| 你的处境 | 我想把这块学懂 | **我下周面试，这句话我会被问到** |
| 姿态 | 引导 | **拷问**（答不上来是正常结局） |
| 底牌 | 常见的想错 | **背诵指纹**（被背烂的那几句原话 + 每句往哪追） |
| 交付物 | 能用自己的话讲一遍 | **一段 60 秒、当场说得出口的回答** |

## 一句八股怎么撑满 40 分钟：五层阶梯

每一份的底牌都按这五层填满，所以模型手里始终有下一问：

| 层 | 问的是 | 答不上来说明 |
| --- | --- | --- |
| **L1 · 定义** | 几个词各自是什么、区别列几条 | 没背过 |
| **L2 · 机制** | 这个区别在系统里**具体是哪个结构、哪一步**造成的 | **背过，但只背了结论** |
| **L3 · 数字** | 差多少？几微秒、几倍、几次 IO | 没上过手 |
| **L4 · 选择** | 给定场景选哪个、代价是什么、什么时候这个选择是错的 | 不会用 |
| **L5 · 边界** | 你刚才那套说法在什么情况下**不成立** | 背得全，但没真懂 |

**通用判卷线：到 L4 才算能过面试，到 L5 才算真的懂，只停在 L1 的一律记成背的。**

## 头尾两幕是这个系列独有的

六幕结构，但第一幕和第六幕别处没有：

- **第一幕 · 先把你背的那版说完**：**模型不许打断、不许点评、不许提示**，
  录下你现在的版本当基线。
- 第二到第五幕：按五层阶梯往下挖，主战场在第三幕。
- **第六幕 · 回炉重讲**：**掐 60 秒**重讲一遍，和第一幕那版**并排比**。

理由很简单：面试现场要交付的不是「你懂」，**是一段说得出口的话**。
所以收尾卡片的第一栏永远是**开场版 vs 收尾版**。

## 怎么用

1. 挑一份，**新开一个空对话**。
2. 把那个文件里 `---` 分隔线**之后**的全部内容复制过去。
3. 什么都别说，等它问第一个问题，**然后像面试一样一口气把你背的那版讲完**。
4. 后面它会开始追。**答不上来是正常结局** —— 这一批不是学习材料，是模拟面试。
5. 五个口令：

   | 口令 | 作用 |
   | --- | --- |
   | `跳过` | 立刻进下一幕 |
   | `提示` | 给一个提示（不是答案） |
   | `直说吧` | 直接讲完整答案 |
   | **`重讲`** | **直接跳到第六幕，重录 60 秒版本并和开场版对比** |
   | `复盘` | 立刻跳到收尾，输出复盘卡片 |

6. **末尾的底牌别自己先读** —— 「背诵指纹」那一栏写的就是你大概率会脱口而出的
   那几句，看了就没得练了。

## 建议的路线

- **一周内要面后端** → `01` → `07` → `14` → `15` → `20` → `29`。
  这六道是出现频率最高的，而且互相不重叠。
- **面中间件/架构岗** → `23` → `24` → `25` → `26` → `28` → `30`。
- **被问麻了想补短板** → 先做 `10`（输入 URL），它会横着暴露你所有的薄弱环节，
  再按暴露出来的方向挑。
- **写 Java** → F 组六份连着做，`32` → `33` → `36` 是一条线。
- **写 Go** → G 组六份连着做，`37` → `38` → `42` 是一条线。

几份之间是串着的：`02` 的同步/异步在 `03` 里落到 epoll 上；
`14` 的页分裂在 `27` 里决定了主键该不该自增；
`24` 的幂等在 `29` 里被单独问一遍；`33` 和 `42` 是同一个问题的两种答案。

## 为什么这么写（几个决定）

- **姿态是拷问，不是引导。** 这一批模拟的就是面试现场，
  答不上来是正常结局，模型不会替你圆场 —— 这一点和学习型那几批是相反的。
- **底牌的主体是「背诵指纹」，不是知识点。** 知识点模型自己会列；
  **「这一问被背烂的那几句原话、听到哪一句该往哪追」才是写死的编辑决策。**
  所以每份底牌里都有一条硬规定：**指纹表只用来决定往哪追，不许把那句话念出来。**
- **每一份都逼数字。** 和 [computer-systems/](../computer-systems/) 那批一个道理：
  **说得出结论说不出数字，就是背的。**
- **不收要动手写的题。** 判据一句话：**闭着眼睛用嘴说得清楚吗？**
  算法题、手写单例、手写 SQL、白板画图都不在这里 —— 这一批练的是视频面试那半边。
- **和已有系列重叠的题不砍。** 判据是粒度，不是「这个名词有没有出现过」：
  `database/` 练排查、这里练口述；`troubleshooting/` 是你问它答、这里是正着被问。
